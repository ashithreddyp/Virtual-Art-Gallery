# 🎨 Virtual Art Gallery

A full-stack virtual art gallery web application where users can browse paintings, create accounts, manage carts, place orders, and administrators can manage the gallery.

---

## Features

- User Registration & Login
- Secure Authentication
- Browse Paintings
- Shopping Cart
- Checkout System
- User Profile
- Order Management
- Admin Dashboard
- MongoDB Database Integration

---

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

### Authentication
- Passport.js
- Express Session
- bcrypt

## Installation

Clone the repository

```bash
git clone https://github.com/ashithreddyp/Virtual-Art-Gallery.git
```

Move into the project

```bash
cd Virtual-Art-Gallery
```

Install dependencies

```bash
npm install
```

Start MongoDB locally.

Run the application

```bash
npm start
```

Open:

```
http://localhost:3000
```
